# <img width="32" alt="Icon" src="https://raw.githubusercontent.com/Yukiroshi/ExpandedPresets/refs/heads/main/ExpandedPresets.svg" /> One preset to rule them all

Expands the existing presets and adds completely new ones. No more guessing which preset is the right one; everything is clean and uniform, without compromising on complexity.

- Lots of small improvements, ranging from clearer descriptions to additional tags.
- Entirely new presets, even for less known features.
- Niche tagging consulted with experts across the globe.
- Everything is made with attention to smallest details.
- Very regular updates, often on a daily basis.
- Requests and suggestions added even the same day.

# Features

## Improved and cleaner version of [Heritage](https://josm.openstreetmap.de/wiki/Presets/Heritage) preset, originally made by [Gmbo](https://github.com/gmbo), [Geozeisig](https://github.com/geozeisig) and [Daniel Capilla](https://github.com/dcapillae)

- Icons are to be made

## Cleaner version of [3D Simple Buildings](https://github.com/kendzi/Simple3dBuildingsPreset) preset, originally made by [Kendzi](https://github.com/kendzi)

- With roof icons by [Mxdanger](https://github.com/mxdanger) (same as OSM Wiki)

## Translations

- English is the base language for all strings

- <img height="16" alt="Flag PL" src="https://raw.githubusercontent.com/Yukiroshi/Flags/refs/heads/main/PL.svg" /> Polish translations provided by kindness of [Yukiro](https://github.com/Yukiroshi) (me, the author)

# Installation

- Open JOSM settings panel (`F12`),
- then look for <img width="20" src="https://josm.openstreetmap.de/browser/trunk/resources/images/dialogs/mapstyle.svg?format=raw"/> Tagging Presets
- type `Expanded Presets` (or author name, `Yukiro`) in the search box:
<img width="300" alt="Zrzut ekranu 2026-10-25 110152" src="https://github.com/user-attachments/assets/254e759a-0fd3-49bc-8124-c3b91f430448" />

- click on it
- then click on the <img width="20" src="https://josm.openstreetmap.de/browser/trunk/resources/images/preferences/activate-right.svg?format=raw"/> blue arrow between the available and active presets
- make sure to disable JOSM internal style and any other styles, which are merged into this one, otherwise there might be a mess!
- don't forget to click <img height="20" src="https://github.com/user-attachments/assets/7a722b4e-fc73-4b8e-86c7-39e1f6726537" /> OK button at the bottom, otherwise it won't save changes!

Alternatively:

See [installation instructions from official JOSM website](https://josm.openstreetmap.de/wiki/Help/Preferences/TaggingPresetPreference#Presets).

Replaces the default and merged presets, make sure to disable them to avoid duplicates!
