# <img width="32" alt="Icon" src="https://raw.githubusercontent.com/Yukiroshi/ExpandedPresets/refs/heads/main/ExpandedPresets.svg" /> One preset to rule them all

Expands the existing presets and adds missing essentials. No more guessing which preset is the right one; everything is clean and uniform, without compromising on complexity.

# Features

## (Work in progress) Improved and cleaner version of [Heritage](https://josm.openstreetmap.de/wiki/Presets/Heritage) preset, originally made by [Gmbo](https://github.com/gmbo), [Geozeisig](https://github.com/geozeisig) and [Daniel Capilla](https://github.com/dcapillae)

## Cleaner version of [3D Simple Buildings](https://github.com/kendzi/Simple3dBuildingsPreset) preset, originally made by [Kendzi](https://github.com/kendzi)

# Installation
See [installation instructions](https://josm.openstreetmap.de/wiki/Help/Preferences/TaggingPresetPreference#Presets) from official JOSM website.

Replaces the default presets, make sure to disable them to avoid duplicates!
